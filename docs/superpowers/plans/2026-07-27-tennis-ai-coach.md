# AI Tennis Coach — план реализации MVP

Дата: 2026-07-27  
Статус: выполняется

## Принятые решения

- Flask backend на Render, статический PWA в `docs/` на GitHub Pages.
- Общий Supabase с Oura-v2.
- Tennis-coach не вызывает Oura API: читает последнюю запись `health_logs` по `OURA_USER_ID`.
- Значения Oura копируются в `match_prep` вместе с датой и ID исходной строки.
- Один активный матч, восстановление после перезапуска, idempotency для событий.
- Счёт — JSON `{sets, game, serving}`, финальный счёт — отдельная строка.
- OpenAI model задаётся через env; базовый недорогой вариант — `gpt-4o-mini`, смена модели не требует правок кода.
- «Паттерны» отложены до накопления данных, но чипы и показатели хранятся структурированно.
